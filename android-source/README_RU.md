# Kindred Android 1.0.35

Эта отдельная ветка подготовлена для сборки Kindred с помощью GitHub Actions.
Основная ветка main содержит сайт и не меняется при загрузке исходников в эту папку.

## Исходный файл
Ожидаемое имя: `Kindred_1_0_35_Unified_Source.zip`.
Загрузите его в папку `android-source/` в этой ветке.
После GitHub-коммита ZIP workflow запустится автоматически: установит Android SDK,
выполнит тесты, Lint и создаст **неподписанный** AAB.

⚠️ ВНИМАНИЕ: репозиторий `nadiiahonda34-svg/kindred` публичный.
Любой ZIP, загруженный сюда, будет доступен другим людям. Если вы не хотите
публиковать исходники Android-приложения, НЕ загружайте архив в эту ветку.
Создайте отдельный приватный репозиторий и перенесите в него workflow.

Для обновления Google Play необходим исходный закрытый upload key. В этом
workflow ключа нет, он не хранится в репозитории. Неподписанный AAB нельзя
отправить в Play Console как готовое обновление.
